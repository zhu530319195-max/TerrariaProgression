# TerrariaProgression — Progression Design v0.1

> 状态：设计基线。用于指导后续实现；若规则发生变化，应同步更新 `DECISIONS.md` 与 `PROJECT_STATUS.md`。

## 1. 模块目标

独立于任何角色外观系统，提供可无限成长、可自由回退、可自由启停、可配置强度的 Terraria/tModLoader 角色成长框架。

核心循环：

`击杀/行动 → 获得经验 → 升级 → 获得天赋点 → 投资能力 → 无限成长`

## 2. 等级与角色数据

- 初始等级：Lv.1
- 等级上限：无
- 默认每升一级获得 1 天赋点
- 单次大量经验允许连续升多级
- 死亡不掉级、不扣经验
- 切换世界保留全部成长
- 单人/联机切换保留全部成长
- 数据归属于 Terraria 角色，而不是世界

需要长期保存：

- `Level`
- `CurrentExperience`
- `TotalExperienceEarned`
- `AvailableTalentPoints`
- `TotalSpentTalentPoints`
- 各天赋等级
- 各天赋启用状态
- 各天赋实际投入点数/成本记录

`TotalExperienceEarned` 不直接参与升级，但保留用于统计、调试及未来扩展。

## 3. 击杀经验

### 3.1 基础公式

`获得经验 = NPC.lifeMax × HpToXpMultiplier × SourceMultiplier`

读取最大生命 `lifeMax`，不是死亡前剩余生命。

### 3.2 HP → XP 比率

- 默认：1.00 XP / 1 最大生命
- 可调范围：0.01 ～ 10.00
- 允许小数

示例：

- 5 HP 兔子，倍率 1.00 → 5 XP
- 100 HP 敌人，倍率 0.50 → 50 XP
- 100 HP 敌人，倍率 0.01 → 1 XP
- 100 HP 敌人，倍率 10.00 → 1000 XP

内部经验应支持小数精度；UI 可按需要格式化显示，避免无意义尾数。

## 4. 升级经验需求

基础公式：

`BaseRequirement = 250 + 50 × (Level - 1) + 10 × (Level - 1)^2`

最终需求：

`RequiredExperience = Min(BaseRequirement, ExperienceRequirementCap)`

### 4.1 单级需求上限

- 默认：50,000 XP
- 玩家可配置
- `0` = 不封顶

等级仍然无限；默认配置下，公式需求达到 50,000 后不再继续上涨。

## 5. NPC 经验资格

### 普通敌怪
正常给予经验。

### Boss
正常按 `lifeMax` 动态计算，不维护手写 Boss 经验表，以便兼容其他内容 MOD。

### 小动物
允许获得经验，例如 5 HP 兔子按普通公式结算。

### 城镇 NPC
默认 0 XP，避免反复击杀刷经验。

### 雕像生成单位
通过独立倍率控制：

- 0.00 = 无经验
- 0.10 = 10%
- 0.50 = 50%
- 1.00 = 100%
- 2.00 = 200%

默认建议 0.00。该值后续由配置暴露给玩家。

### 特殊 NPC 风险
实现时必须防止以下情况重复结算：

- 世界吞噬者、毁灭者等多节实体
- 多阶段 Boss
- 主体 + 附属部位
- 死亡时生成/分裂的子实体
- 同一死亡回调重复触发

具体技术策略在 P0/P1 实现时验证。

## 6. 多人经验

禁止“最后一击独占全部经验”。

采用有效伤害/参与贡献分配，例如：

- 目标最大生命 1000
- 玩家 A 贡献 70%
- 玩家 B 贡献 30%
- A 获得 700 基础 XP
- B 获得 300 基础 XP

召唤物、持续伤害、合法玩家投射物等尽量归属真实玩家。

最终经验结算以服务器为权威，客户端只接收结果与 UI 更新。

## 7. 天赋通用模型

每项天赋至少拥有：

- `TalentLevel`
- `Enabled`
- `MaxLevel`
- `EffectPerLevel`
- `TalentPointCost`
- `InvestedPoints`

玩家可执行：

- 升级
- 回退一级
- 全部回退
- 开启
- 关闭

### 7.1 关闭 ≠ 回退

关闭：

- 等级不变
- 已投入点数不变
- 效果暂时失效

回退：

- 降低天赋等级
- 返还该等级实际支付的点数

### 7.2 洗点

当前设计：免费、无限次数回退。

必须保存实际支付成本，不能按照“当前配置价格”重新计算退款，否则玩家修改配置可能复制天赋点。

### 7.3 天赋技术类型

- A：无限数值成长
- B：有限等级成长
- C：一次性永久解锁
- D：特殊功能/模式，可主动开关

约定：`MaxLevel = 0` 表示无等级上限。

## 8. 第一类：基础属性

候选目录：

- 最大生命（A）
- 最大魔力（A）
- 防御力（A）
- 移动速度（A）
- 移动加速度（A/B）
- 跳跃高度（A/B）
- 跳跃速度（A/B）
- 击退抗性（B）
- 幸运（A/B）
- 最大呼吸值（A/B）

暂定示例值（尚未最终平衡）：

- 最大生命：+5 HP / Lv
- 最大魔力：+5 MP / Lv
- 防御：+1 / Lv
- 移动速度：+1% / Lv

最大生命/魔力开关不得成为免费恢复手段。提升最大值时不自动补满；关闭导致上限下降时仅截断当前值，不额外造成伤害或触发恢复。

## 9. 第二类：恢复与续航

候选目录：固定生命恢复、自然生命恢复速度、固定魔力恢复、魔力恢复速度、魔力恢复延迟缩短、治疗效果、魔力恢复物品效果、红心恢复量、魔力星恢复量、药水病缩短、Debuff 时间缩短、综合生命恢复强化、综合魔力续航。

具体默认数值、上限、成本尚未定稿。

## 10. 第三类：战斗

第一阶段优先通用属性：

- 全局伤害
- 全局攻击速度
- 暴击率
- 暴击伤害
- 护甲穿透
- 击退强度
- 弹射物速度
- 弹药节约
- 魔力消耗降低
- 召唤物上限
- 哨兵上限
- 召唤物击退
- 无敌帧强化（需谨慎）

后续可扩展职业专项：近战、远程、魔法、召唤等。

原则：优先通过 tModLoader 的 `DamageClass`/标准属性接口实现，不硬编码武器名单，以提高第三方 MOD 兼容性。

## 11. 第四类：经济与资源

### 金钱
金币掉落倍率、商店购买折扣、出售价格提高、重铸折扣。

### 敌人战利品
战利品数量倍率、战利品掉率倍率、稀有战利品倍率、Boss 掉落数量、宝藏袋收益。

数量倍率与概率倍率必须分离。例如 1% 掉 1 个：

- 概率 ×2 → 2% 掉 1 个
- 数量 ×2 → 1% 掉 2 个

小数数量使用概率尾数，例如 12.5 个 = 12 个必得 + 50% 概率额外 1 个。

### 采集资源
矿石产量、木材产量、草药产量、宝石产量、钓鱼产量、宝匣概率、鱼饵节约、物品拾取范围。

掉落/数量倍率应允许配置是否作用于普通材料、消耗品、弹药、武器、护甲、饰品、Boss 物品、宝藏袋、坐骑、宠物、MOD 物品等类别。

## 12. 第五类：功能型 / 饰品能力

原则：直接赋予角色功能，不要求占据装备栏，也不依赖隐藏装备伪装。

### 移动能力
多段跳、无坠落伤害、自动跳跃、冲刺、攀墙/滑墙、游泳强化、飞行、飞行时间。

多段跳建议：每级增加一次额外跳跃；最大等级可配置。

### 环境生存
水下呼吸、水上行走、岩浆行走、岩浆免疫、炽热方块免疫、火焰抗性、蜂蜜机动、环境伤害抗性。

### 信息饰品能力
时间、深度、罗盘、天气/月相、钓鱼信息、DPS、敌人数量、稀有生物探测、金属/宝藏探测、击杀计数、雷达信息。

### 异常状态免疫
可逐项解锁中毒、流血、缓慢、虚弱、破甲、沉默、诅咒、混乱、黑暗、寒冷、燃烧等免疫；每项仍可单独关闭。

## 13. 第六类：超凡能力

### 极速挖矿
可从高速逐步提升到接近瞬挖/瞬挖；必须允许独立开关。

### 范围挖矿
示例：Lv.0 = 1×1，Lv.1 = 3×3，Lv.2 = 5×5，Lv.3 = 7×7，Lv.4 = 9×9。

“已解锁最大范围”与“当前使用范围”分离。玩家解锁 9×9 后仍可切回更小范围，避免建造时误拆。

### 矿脉连锁挖掘
破坏一个矿块后搜索相邻同类型矿块并连锁破坏。可配置启用、最大连锁数量、是否仅矿石、是否支持 MOD 矿石。

### 一键伐木
合法攻击树干后整棵树一次性处理，与木材产量倍率分开计算。

### 范围采集 / 自动补种
可扩展草药、仙人掌、植物等范围采集；自动补种应消耗合法种子/材料，并允许关闭。

### 攻击破坏地形
攻击命中附近可按等级破坏一定半径方块。属于高风险能力，默认关闭，并保护箱子、家具、晶塔、祭坛、机关、门/工作站、地牢/神庙等特殊砖及其他受保护对象。

多人服务器必须提供总开关；服务器禁止时客户端不能自行修改世界。

## 14. 天赋配置模型

每个天赋尽量支持：是否允许、默认效果、每级效果、最大等级、基础升级成本、成本成长规则。

成本至少支持：

1. 固定成本（如每级 1 点）
2. 递增成本（如 1、2、3……）
3. 一次性价格（如 5 点解锁无坠落伤害）

数值型成长默认更适合固定成本；特殊能力默认更适合一次性或递增成本。具体值尚未定稿。

## 15. UI 原则

顶层长期展示：角色等级、当前经验/下级经验需求、总获得经验、可用天赋点、已投入天赋点。

六个分类页：基础属性、恢复续航、战斗、经济资源、功能能力、超凡能力。

每项天赋显示：当前等级、当前效果、下一级效果、升级消耗、累计投入、`[-1]`、`[+1]`、`[全部回退]`、`[启用/关闭]`。

支持：重置当前天赋、重置当前分类、重置全部天赋、全部启用、全部关闭。

## 16. 联机与权限原则

角色成长数据绑定角色保存。

XP 结算、多人贡献分配，以及范围挖矿、矿脉挖掘、一键伐木、范围采集、自动补种、攻击破坏地形等公共世界修改行为最终以服务器为权威。

## 17. 开发优先级

### P0 核心
等级、经验、封顶、角色存档、天赋点、升级、回退/启停基础模型、配置、联机同步基础。

### P1 稳定数值天赋
最大 HP/MP、防御、移动速度、生命/魔力恢复、全局伤害、攻击速度、暴击、护甲穿透、金币倍率、掉落数量、掉落概率、采矿/伐木产量等。

### P2 原版功能能力
多段跳、坠落免疫、水下呼吸、水/岩浆能力、信息饰品功能、异常免疫等。

### P3 超凡世界能力
极速挖矿、范围挖矿、矿脉挖掘、一键伐木、范围采集、自动补种、攻击破坏地形。

## 18. 当前未定事项

- P1 每项天赋的默认每级效果
- P1 每项天赋默认价格
- 有限天赋的默认最大等级
- 各类软上限/硬上限
- 最终 UI 风格与快捷键
- 复杂 Boss 的经验去重/主体识别策略
- 动态战利品倍率的最终技术方案

这些项目不得由实现阶段擅自当成已定稿规则。
