## 测试方法的边界

模拟的玩家与命中消息用来测试服务器代码、角色/实体回调和网络解码；**没有两台真实客户端参加自动测试**。持续伤害来源、Steam 网络实际传输、真实角色文件切换、实际世界吞噬者/毁灭者战斗和第三方内容 MOD 仍需人工验收。

测试模组 `ProgressionHarness` 与正式 MOD 分离，只在带 `TP_CI_HARNESS=1` 的临时专用服务器环境执行。它在世界加载完成、网络线程启动前初始化模拟角色，结束后关闭测试进程，不应安装到正常存档。

本地云环境无法完成运行启动：官方 MonoMod 初始化读取 `/proc` 时遇到权限限制。未修改 tModLoader 或权限控制来绕过该限制，改用 GitHub 标准 Linux 环境取得运行证据。

首轮 CI 已证明正式 MOD 和专用服务器能加载启动，但空服逐帧测试入口未触发而超时；第二轮发现测试角色未初始化。最终修正测试夹具后上述全部检查通过。失败记录保留，没有将失败检查改成跳过或假通过。
