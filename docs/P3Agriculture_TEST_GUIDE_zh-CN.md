# 0.11.1 采集修复＋批量升级：安装与验收

本批已通过玩家实机验收；92项天赋，存档v3，协议14。环境：tModLoader v2026.07.3.0 / Terraria 1.4.4.9 / .NET 8。

## 安装

1. 退出游戏，备份角色／世界以及旧版成长MOD。
2. 打开tModLoader模组文件夹，用本包`TerrariaProgression.tmod`替换旧文件，保持只启用一份。不要安装ProgressionHarness测试模组。
3. 重新加载，进入测试世界。确认原角色等级、天赋、投入点数仍在。
4. P打开天赋面板，在“采集与钓鱼 → 拾取与收获”找到范围收割、自动补种。

## 本次优先复验：不用关Alt即可补挖／单株收割

1. 学习范围挖矿，按Alt开启。先挖一片普通石头，等范围处理结束；如果有留块，保持Alt开启，直接将鼠标对准留块用镐挖。应能正常手动挖，不再必须关Alt。
2. 用同一把镐分别在Alt开／关时直接挖沙块、带电线的方块、普通石头。手动破坏能力应一致；周围电线、家具支撑、沙块仍不会被范围顺带批量拆掉。镐力不足的矿石两种状态都不能强挖。
3. 学习范围收割，夜晚用普通镐点击一株已长大但尚不能产种的太阳花。Alt保持开启：应单株收获，邻株不因这一击启动范围收割。
4. 再学习自动补种，背包放太阳花种子，重复上一步：应原位补种并扣1枚；没有对应种子时仍收获，留空。
5. 白天对当前能产种的草药使用范围收割：应继续批量收合格草药并保留范围内幼苗，不能因手动回退取消幼苗保护。
6. 如果仍有Alt关时能挖、开时不能挖的目标，请截图包含方块、手持工具和提示；附方块名称、是否MOD方块，便于复现具体类型。当前截图只包含通用提示，未知类型不能算已修复。

## 本次优先复验：一次升级多级

1. 按P打开天赋，选一个普通数值天赋。右侧操作区可滚动；应有+1、+10、+100、+300、+1000按钮，显示对应总点数。
2. 点数足够时依次点击四个新按钮：等级分别增加10／100／300／1000，累计增加1410，普通1点/级天赋累计扣1410点。
3. 点数不足时相应按钮不可用，不会只买一部分或扣成负数。
4. 将可调天赋先关闭或调低当前强度，再批量升级：开关／所选强度保持不变。原本最大强度随已购等级增加。
5. 回退一级只退该级实际点数；全部退回当前天赋返还全部实际投入。退出重进后等级和投入应保留。
6. 选择自动补种等一次性功能：仍只花2点解锁一次，批量按钮不可用。
7. 本版协议14；如果以后联机，请所有客户端与服务器同时升级。本轮自动网络测试不代表真实多人验收。

## 1. Alt现在只按一下

1. 进入世界后先用镐挖石头，应是普通单格操作。
2. 学习范围挖矿，按一下左Alt，松手，再挖石头：应批量挖掘。
3. 再按一下Alt，看到关闭提示，再挖应恢复普通操作。
4. G切到矿脉，按一下Alt开启后采矿；持斧砍树也无需一直按住。范围／连矿／伐木不能重复一起触发。
5. 大范围作业仍在进行时按Alt关闭：剩余方块应停止处理，已挖掉的保留。联机取消以服务器收到操作为准。
6. 退出重进世界，默认关闭。聊天、打开菜单或操作界面时按Alt不应切换。
7. 可在“设置 → 控制 → 模组控制”改绑，也可输入`/tpgather toggle`切换。

## 2. 范围收割

1. 花1点学习范围收割。准备几株已能产种子的草药，旁边留幼苗，推荐白天测试已长大的太阳花。
2. 按一下Alt开启，然后**用普通镐点击一株当前能产种子的草药本身**：应处理以目标为中心的3×3内合格草药，幼苗保留。
3. 2级为5×5；10级21×21。把10级当前强度降到1，应恢复3×3，已购等级仍为10。
4. 混种不同草药时，只处理当前原生可产种的那些。未开花／未达条件的成熟草药可能留下，这是预期。
5. 在种植盆、黏土盆和合法地面分别试：只收草药，不拆盆、不挖地面。
6. 关闭范围收割天赋后，不能继续触发范围收割。Alt也统一控制旧挖矿功能，避免在药田下方直接点击泥土测试。

## 3. 自动补种

1. 花2点解锁自动补种。收一株能产种的草药，应收获药材并在原位置留下同种幼苗，种子比总收获少1枚。
2. 背包有种子时，本次收获优先用于补种，背包数量应保持。
3. 关闭Alt批量开关，用普通镐单株收割：仍自动补种，不要求购买范围收割。
4. 可在夜晚用镐收已经长大但未开花的太阳花；背包有太阳花种子时扣1枚补种，无对应种子时收割照常完成，位置留空。
5. 只带其他种类的种子：不能替代对应种子。附近地上原有种子也不会被自动扣除。
6. 关闭自动补种天赋：仍能范围收割，但不会补种。关闭不退款；退款应返还实际投入2点。
7. 若原位种植条件不合，补种跳过，种子不扣。正常药田通常不会出现此情况，失败路径已安排自动检查。

## 4. 产量与保护

- 有草药产量10级时，药材及种子按原倍率产出，再支付每株1枚补种种子；不得先扣种再对剩余种子翻倍，也不再次增产。
- 服务器设置新增“允许范围收割”“允许自动补种”；公共总许可、保护区、单次上限、每帧预算沿用。单次上限计实际收割株数，包含起点。
- 单次上限设为2：一个批次最多收2株，补回的幼苗不重复收。每帧预算较小时大范围会逐步完成。
- 批量过程中切工具、关闭或退款相关天赋、离开起点可达范围应中止后续操作。
- 生长法杖／再生之斧的特殊农业操作、树木自动种树、非草药植物和第三方植物不在本批适配范围。请使用普通镐验收。
