# P2-B 0.5.0 安装与测试

PR #6 的 P2-A 已验收合并。本批只需重点测试下面9项新功能；自动测试结果见包内 BUILD_INFO.txt。P2-B PR 保持未合并，等你实机验收。

## 安装
退出世界，备份角色的 .plr 与 .tplr。游戏“模组管理”打开 Mods 文件夹，用测试包中的 TerrariaProgression.tmod 覆盖同名文件，然后重载模组。不要同时保留两份。源码包是开发备份，不放进 Mods。

服务器与全部客户端统一更新到0.5.0。存档格式仍是v3；若回到旧MOD，请恢复更新前角色备份，避免旧版不认识新天赋。自动跳跃仍已取消，既有退款不会重复。

## 准备
用测试角色；先卸下冲刺、攀墙、冰鞋、喷漆和钓鱼便利饰品，避免装备掩盖开关差异。翅膀留作飞行测试。
在MOD配置打开“开发测试命令”，输入：

```text
/tpgivexp 1000000
/tptalents
```

P键也可开关页面。“功能能力”内新增移动、建筑／工具、钓鱼／采集相关条目，每项2点，共18点即可全解锁；关闭不退点，回退退回实付2点。

## 最短验收表

| 测试 | 操作 | 应看到 |
| --- | --- | --- |
| 冲刺 | 双击A或D；关闭后等待当前冲刺结束再试 | 开启可横向冲刺，关闭后不能新发起；装备克盾后使用克盾效果 |
| 攀墙 | 只开攀墙，跳到实心竖墙旁并朝墙按住，再反复按跳跃 | 贴墙停留，可蹬墙向上；按下可下滑，不是按上直接爬绳 |
| 滑墙 | 关攀墙，只开滑墙，按住朝墙方向 | 沿墙缓降；两项全关后正常下落。两项同开时贴墙优先 |
| 无限飞行 | 穿普通翅膀，先落地，再长按跳跃超过原飞行时间；空中关闭 | 开启可持续飞行，速度不增加；关闭后按保留的剩余时间耗尽。没有翅膀不会凭空飞行 |
| 冰面防滑 | 在同一段冰面上比较开启／关闭时的起步、松键、反向 | 开启后抓地改善；真实冰鞋的效果不会被天赋关闭抹掉 |
| 建筑标尺／格线 | 解锁后打开背包，在背包旁原版建筑辅助按钮启用格线／标尺显示 | 出现对应显示；关闭天赋停止天赋提供的格线。原版自带标尺保留 |
| 自动喷漆 | 背包放红漆，在原版建筑辅助按钮启用喷漆，放置木块、家具和背景墙 | 新建物体上色，涂料正常减少；关天赋或关原版喷漆按钮后新放置物不自动上色；没有涂料仍能建造 |
| 钓线不断 | 普通水池正常钓鱼、收竿，观察多次收获 | 不再因原版随机断线丢失收获；鱼饵照常消耗。少量成功收竿不能单独证明概率，自动测试已覆盖同一次断线随机结果 |
| 熔岩钓鱼 | 普通鱼竿＋普通鱼饵，在足够大的岩浆池抛竿等待 | 可以正常钓到岩浆鱼获；没有鱼饵不能钓，不附带岩浆免疫。岩浆等待可能较长 |

无限飞行开启时若时间已耗尽，请先落地一次；它不作用于坐骑或单独火箭靴。攀墙／滑墙保留原生蹬墙跳行为。原版建筑辅助按钮的具体位置随界面缩放变化，悬停可查看名称；若按钮此前关闭，解锁不会擅自改你的设置。

## 点数、保存与界面
任选一项：解锁扣2点，重复购买不能再扣；关闭不退点，回退退2点。关闭滑墙、启用攀墙后，重进、换世界再检查两项状态分别保留。已有P2-A天赋、等级、点数应保持。200%界面缩放检查新增条目滚动和右侧说明不重叠。

有联机条件时，两人使用同版，检查另一人能看到冲刺／贴墙／飞行位置变化和喷漆结果，退出重进天赋保持。暂未测试联机可单独注明，不影响你报告已经完成的单人项目。

反馈格式：加载／冲刺／攀墙／滑墙／飞行／冰面／格线／喷漆／钓线／岩浆钓鱼／保存，各填“通过、异常、未测”。异常附截图和 client.log；联机异常再附 server.log 及 MOD 列表。
