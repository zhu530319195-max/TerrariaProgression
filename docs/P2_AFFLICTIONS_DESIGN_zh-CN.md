## 2. 异常伤害作用范围

- 只强化成长天赋施加的燃烧、中毒、霜冻、诅咒焰、毒液，分别追踪有效来源和天赋施加的有效期。
- 不把敌人身上的全部扣血直接乘倍率；武器原带的异常、环境异常和未知第三方MOD异常不纳入本批增伤。
- 灵液只按原生效果降低防御，升级延长时间；异常伤害强化不提高其减防数值。
- 各异常持续时间升级与统一的伤害强化相互独立。例：某个受支持异常基础每秒伤害为D，伤害强化当前强度10时为3D，而不是每次命中再额外叠一份3D。
- 实现须按固定tModLoader v2026.07.3.0核对原生状态、伤害和互斥关系；不得为适配接口而静默改为其他异常或改变批准的数值。

## 3. 命中、刷新与免疫

| 情况 | 已确认行为 |
|---|---|
| 攻击来源 | 玩家武器与所属弹幕，包括召唤物，对敌人造成有效命中时尝试施加 |
| 触发概率 | 每次有效命中必定尝试施加，不再额外抽概率；目标免疫时仍不生效 |
| 目标范围 | 敌人；不增加PvP、城镇NPC等新攻击范围 |
| 同种异常重复命中 | 刷新持续时间；不把每次持续时间累加，不叠加多份同种持续伤害，不用短效果缩短已有长效果 |
| 不同异常 | 按原生规则共存、替换和免疫，不强行叠加原生不允许共存的状态 |
| 持续伤害 | 不暴击、不再次触发攻击附加异常或命中特效，避免循环触发 |
| 击杀 | 经验和掉落沿用现有结算；不增加第二份结算、不自动完成私人掉落增产 |

## 4. 多人来源与强度调节

- 同一目标、同一种异常分别记录各玩家仍有效的天赋施加来源；额外增伤取最高有效值，不相加或相乘。弱效果不覆盖强效果。
- 最高来源失效后，按剩余有效来源重新选择；没有有效天赋来源时不追加天赋增伤。不能将别人的异常或武器延续的时间算作本人的新增天赋来源。
- 按施加者当前启用强度计算仍有效的天赋异常增伤。调低强度即时降低该来源增伤；关闭／完全退款后该来源额外强化停止，已施加的原生异常不因此被清除。
- 实现与测试必须保留NPC来源生命周期和联机权威边界，防止NPC槽位复用、旧连接／旧角色记录污染新目标／新角色。
- 本规则要求正确处理多人来源，但不将本批自动检查记为两个真实客户端的实机验收。历史真实多人验证仍单列。
