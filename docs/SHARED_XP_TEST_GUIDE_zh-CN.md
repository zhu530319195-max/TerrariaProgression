# 无尽潜能0.14.0：全服经验共享安装与测试

本批新增一个免费服务器设置，不是新天赋，仍100项。默认关闭，旧角色和旧配置可继续使用。存档v3、协议17不变，所有玩家与服务器请统一升级0.14.0。新选项待玩家实机验收；自动检查不等于真实多人通过。

## 安装与打开开关

1. 退出游戏，备份角色和世界。解压测试包，把`TerrariaProgression.tmod`放入tModLoader的Mods目录，覆盖旧版同名文件。不要安装ProgressionHarness。
2. 启动游戏，确认“无尽潜能 · Boundless Potential”版本0.14.0。
3. **房主开服前**进入模组配置 → 无尽潜能：成长规则（服务器），找到“全服经验共享”，打开并保存，再创建房间。
4. 专用服务器：先停止服务器，在原有`TerrariaProgression_ProgressionConfig.json`中把`"ShareExperienceServerWide": false`改为`true`，保存重启。旧文件若没有此项，可先运行新版生成配置，再停服编辑。
5. 沿用原有权限，普通玩家不能在联机中修改服务器规则。测试切换开关时，房主先退回菜单修改并重新开服；不要以为客户端设置界面保存失败仍已生效。

## 两个人最容易照做的测试

建议用两个新建的测试角色，累计经验小、看变化更清楚。P面板中记录“累计经验”，比较增加量，不比较经验条长度或等级，因为两人的原等级可能不同。

1. 共享开启：B待在远处，不加入A的队伍、不攻击。A击杀一只普通怪。两人的累计经验应增加相同数值；若本次提供100经验，两人各加100，不是各50，也不是A额外多领。
2. 两人都攻击同一只怪后击杀：两人仍各得完整经验，不按伤害比例拆分，不重复领取。
3. B死亡等待复活时，A击杀一只怪；B复活后查看累计经验，应有这次完整收益。
4. B退出房间，A杀怪，再让B进入：B不会补领离线期间的经验。重新在线后再杀一只，两人继续各领一份。
5. 关闭共享并重新开服：B不攻击、A独自杀怪，应仅A获得经验；两人共同参战时按原有实际伤害贡献分配。
6. 原有等级、天赋点、所选强度和投入应保留。开关变化只影响之后结算，不会把低等级角色自动补到高等级角色。

## 其他保留规则

- 不限制距离、队伍或是否参战，死亡等待复活不排除；刚连入但角色数据还没同步完成时暂不领取。
- 按结算时的在线名单和服务器开关处理，已结算击杀不追溯。共享替代原有贡献分配，参战者每次只领一份。
- 仍需存在合法玩家伤害贡献；纯环境或无归属击杀不向全服发经验。雕像经验倍率、城镇NPC排除与多节／分裂实体去重保留。
- 开发命令直接加经验不算击杀，不会共享。每级天赋点仍按服务器当前设置计算，各角色独立保存。
- “恢复默认天赋等级限制”按钮不会关闭这个共享开关，因为该按钮只重置等级限制。

可以直接反馈“共享经验通过”，或说明哪一步不符合预期，并附两人累计经验前后数值、服务器开关截图、是否死亡／掉线。
