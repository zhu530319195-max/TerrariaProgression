# P3采集基础＋攻击范围补全：0.10.0验收说明

本包待玩家实机验收。共90项天赋，存档v3，联机协议12。目标：tModLoader v2026.07.3.0 / Terraria 1.4.4.9 / .NET 8。

## 安装

1. 退出游戏。在tModLoader的“模组管理”中打开模组文件夹，先保留旧版`.tmod`作为备份。
2. 把测试包里的`TerrariaProgression.tmod`覆盖进去。只启用这一份成长MOD，不启用ProgressionHarness。
3. 重新加载MOD，进入角色和世界。先确认原有等级、点数和天赋正常。
4. 本次会改变世界方块，请在测试世界试用，或先复制一份常用世界。

## 操作

按P打开天赋菜单，在“采集与钓鱼 → 采集与拾取”中找到三个新天赋。范围挖矿／矿脉连锁每级1点；一键伐木一次2点。

- **按住左Alt并使用工具**才启动批量采集。松开后新动作恢复普通工具操作；已开始的作业继续分批完成。
- **按G**切换范围挖矿／矿脉连锁，聊天栏显示当前模式。持斧砍原版树时自动选择一键伐木。
- 也可输入`/tpgather area`或`/tpgather vein`切换模式。
- 热键可在“设置 → 控制 → 模组控制”里修改。打开天赋菜单或输入聊天时不触发。
- 要中止正在执行的作业，切换到另一种工具／物品，或关闭、退款、调整相关天赋。离开首格的工具可达范围也会停止。
- 开始时必须先按正常工具效率挖掉第一格；之后额外方块分批处理，大范围可能需要稍等。

## 1. 范围挖矿

1. 准备一片石块，升级范围挖矿到1级，G切到范围模式。
2. 不按Alt挖一下：仍是普通挖矿。
3. 按住Alt挖中间一格：应清掉以该格为中心的3×3，外圈保留。
4. 升到2级再试，应为5×5；10级为21×21。降低当前强度到1应恢复3×3，已购等级和投入不变。
5. 用铜镐挖石块旁的陨石：石块可挖，镐力不足的陨石不能被额外挖掉。
6. 在箱子／工作台附近试用：家具、箱子及紧邻的支撑方块应保留。电线、执行器、沙块和沙块支撑、地牢／神庙砖也跳过。

这些保护是保守过滤，家具旁多留几块石头属于预期。普通工具操作不受本MOD批量保护限制。

## 2. 矿脉连锁

1. 学习1级矿脉连锁，用G切到矿脉模式。
2. 找到铜矿或其他同种矿脉，按住Alt正常挖掉一格。
3. 相连矿石继续挖掘，斜角相邻也算；旁边泥土、石头、另一种矿石及隔着空隙的矿石保留。
4. 1级单次最多25格，10级250格，都包含第一格。矿脉较小就只处理实际相连部分。
5. 可同时购买范围挖矿，但一次只执行选中的一个模式，不会互相触发。
6. 若有10级矿石产量，统计落地铜矿：每实际挖掉一格应获得2个铜矿，不出现同一格重复增产。

默认支持原版矿石。服务器允许MOD矿石后，才尝试其原生矿石标记和镐力／破坏规则；未知MOD兼容性仍需逐项验证。

## 3. 一键伐木

1. 花2点解锁。持斧按住Alt砍树干中间一格，正常砍断后，同一棵树的上半截和下方树桩都应清理。
2. 紧邻的另一棵树、地面、木材建造的墙体／房屋应保留。
3. 关闭天赋再试：恢复原版砍树规则。原版从底部砍树本来就会倒树，本天赋的补充是中段起砍也清理同树残余树桩。
4. 有木材产量／宝石产量时沿用原倍率，不额外重算第二遍。
5. 普通树、棕榈、宝石树可分别试；不含MOD树、巨型蘑菇、仙人掌和竹子。

整棵树触及保护区域／对象或超过单次数量上限时拒绝启动，避免留下半棵受保护树。

## 4. 服务器控制和退款

在“模组配置 → TerrariaProgression”中查看：批量采集总开关、三项独立许可、MOD矿石开关、单次方块上限、每帧处理预算和保护矩形区域。服务器配置需在开服前修改，或改专用服务器配置后重启。

1. 把单次上限设成3，范围挖矿应最多破坏3格，包含第一格。等级／点数不变。
2. 上限0表示总量不限；每帧预算仍有效。默认上限1000、预算32。
3. 关闭总开关后，按Alt不能启动批量采集；不按Alt仍可正常使用工具。
4. `/tpgather coords`显示鼠标方块X/Y，可用于填写保护区域的左上角；Width/Height是方块宽高。
5. 关闭天赋不退款；退款返还实际投入。重进游戏后新天赋等级、开关、强度和采集模式应保留。

多人协议要求所有客户端与服务器使用同版。自动检查覆盖服务器请求校验和单次结算；真实多人实机验收仍单列，未自动通过。

## 5. 鞭子和链锤

沿用“战斗与召唤 → 武器操控 → 近战攻击范围”，没有新增收费天赋。

1. 用皮鞭或荆鞭，先关闭范围天赋观察距离，再开启10级：鞭长和实际可命中的距离应约两倍；原有标记和召唤效果保留。
2. 换链球／蓝月／太极连枷／花冠。比较关闭与10级时的旋转范围、甩出距离；用稍远的敌人确认能命中。
3. 对墙甩出、让锤头落地、松手收回，动作应正常，不持续漂移或越用越长。
4. 将当前强度调为3，应为约1.3倍；关闭恢复原范围。其他攻击速度加成可能影响链锤原本的甩出表现，比较时保持其他装备和天赋相同。
5. 再试普通剑、铜短剑、长矛：此前范围效果仍正常。剑气、子弹、悠悠球不因本次适配自动扩大。

链锤有原版900像素离身清除保护。本版在极高强度时限制范围输出，避免甩出即消失；天赋等级和投入仍无限保存。未知MOD特殊武器不宣称已适配。

## 反馈格式

可直接回复：

- 加载／旧存档：通过或现象
- 范围挖矿／保护：通过或现象
- 矿脉连锁／产量：通过或现象
- 一键伐木：通过或树种与现象
- 设置／退款／重进：通过或现象
- 鞭子／链锤／旧武器：通过或武器名与现象

药水病缩短、原有钓鱼产量、特殊／多阶段Boss、多人独立掉落增产以及分层暴击，不属于本次通过范围；保留此前各自状态。
