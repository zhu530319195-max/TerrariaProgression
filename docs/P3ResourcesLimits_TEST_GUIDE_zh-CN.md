# 0.13.0 资源补全与服务器等级限制：安装与验收

本包为待玩家实机验收版本。自动检查结果和精确提交以包内BUILD_INFO为准；自动网络检查不等于真实多人验收。不要把测试用ProgressionHarness装进日常游戏。

## 安装

1. 退出游戏并备份角色和世界。把玩家测试包解压，只取`TerrariaProgression.tmod`。
2. 放入`文档/My Games/Terraria/tModLoader/Mods`，覆盖旧版同名文件；若文档受OneDrive管理，以tModLoader的“打开模组文件夹”为准。
3. 启动tModLoader，确认Terraria Progression为0.13.0并启用。原等级、天赋投入、开关和已选强度应保留。
4. P打开面板；左Alt按一下开启批量，再按一下关闭；G切换范围／矿脉；K切换额外挖矿保护，进世界默认关闭。新旧客户端与服务器不能混用，协议17。

## 建议先测服务器限制（单人即可）

设置入口：暂停菜单→设置／模组配置→Terraria Progression成长规则（服务器）。点击保存后生效。联机沿用旧权限：开服前设置，专用服务器修改配置文件后重启；普通客户端不能远程改服务器规则。

1. 全局上限先保持`-1`。给“基础方块产量”买20级，把当前强度设为15。
2. 全局上限改`10`并保存。面板应仍显示已购20级、已选15级，但实际生效10级；再买不能超限。挖1块泥土应掉2块。
3. 全局改`0`并保存。已购等级和投入应保留，天赋暂停；挖1块泥土应只掉1块，不能再购买。
4. 在“单项天赋等级覆盖”点`+`：左框填`BasicBlockYield`，右框填`12`，保存。此时全局0但这一项可生效至12级。其他天赋仍被禁用。每个天赋详情都显示可复制／抄写的稳定ID。
5. 点击“恢复默认天赋等级限制”，确认全局变`-1`、单项列表清空，再保存。原20级和已选15级可继续使用；此前改过的每级天赋点等其他服务器设置应保持。
6. 单项设`BasicBlockYield=12`，先退款该项，再买10级。点击`+100`时实际按钮应显示只买2级、花2点，购买后为12级。若只剩1点，应完全不购买，不能偷买1级。
7. 给任意一次性功能设上限100，仍只能解锁1级。对上限0的已有天赋点击退款，应返还详情中实际投入，不按限级后的等级少退。

单项支持-1／0／正整数；未列出的继承全局，重复ID以最后一项为准。新设置缺失的旧配置默认无限。限制与角色存档分开保存，跨服或恢复默认不永久裁掉原等级。

## 30种基础方块

把“基础方块产量”实际强度设为10。先用普通镐挖自己放下的10块泥土，再开Alt做范围挖矿，各自应获得20块。天然块同样生效。矿石仍用矿石产量，宝石仍用宝石产量，不双重相乘。

| 分组 | 首批覆盖 |
|---|---|
| 土质 | 泥土、淤泥、黏土、灰烬 |
| 石质 | 石头、黑檀石、猩红石、珍珠石、花岗岩、大理石 |
| 沙 | 沙、黑檀沙、猩红沙、珍珠沙 |
| 硬化沙 | 硬化沙、硬化黑檀沙、硬化猩红沙、硬化珍珠沙 |
| 砂岩 | 砂岩、黑檀砂岩、猩红砂岩、珍珠砂岩 |
| 雪冰 | 雪块、冰块、紫冰、红冰、粉冰 |
| 提炼原料 | 泥沙、雪泥、沙漠化石 |

首批支持可确认玩家主人的六种原版炸弹／雷管及其黏性、弹力版本；即使没买爆破范围，基础方块产量也应生效。爆炸仍一次处理完整原版圆形，墙壁继续遵守原生条件。未知第三方爆炸物不保证归属和增产。

## 草药加速

1. 种下太阳花、月光草、闪耀根、死亡草、幌菊、火焰花、寒颤棘。合法地面、黏土盆或种植盆均可。
2. “植物生长加速”设实际10级，站在药园50格以内。目标为原版随机生长更新的三倍；各株随机，不要求同一秒成熟。
3. 普通墙不会挡住加速；走到50格外、死亡或关闭天赋后，仅停止额外加速。不会给整张地图或离线角色继续加速。
4. 月光草仍要遵守夜晚产种等条件，不能因为加速便全天产种；多人重叠只取最高，不相加。本批多人逻辑只做自动验证，真实多人实测暂缓。

极端等级下，额外草药更新全服每帧最多4096次；等级与投入不截断。蘑菇、仙人掌、竹子、南瓜与树木生长不包含在此天赋里。

## 锤力与范围拆墙

1. 拿木锤，买“锤力增强”10级。物品提示应显示天赋后额外100个百分点；不是把原锤力乘两倍。已有方块破坏效率继续管锤速。
2. 造一片背景墙，买“范围拆墙”1级，开启Alt并锤墙：以本次实际锤击的墙格为中心清理3×3；调到10级为21×21。
3. 自然墙需从原版允许的位置开始，不能直接从连续自然墙内部挖洞。范围操作只处理墙，不批量改变前景斜坡，不批量敲祭坛。
4. 开始较大的拆墙后关闭Alt或切工具，剩余作业应停止。服务器关闭对应许可或降低限级后同样不能继续旧强度。

## 自动补种树苗

1. 买“自动补种树苗”（2点）并开启。背包放普通橡实，关闭Alt，正常从根部砍一棵普通树：砍完后原根应出现树苗。
2. 从树中段砍，未清理残桩时不能在残桩内硬塞树苗；手动清完树桩再看补种。此天赋不会额外授予一键伐木。
3. 开启一键伐木并开Alt，从中段砍：整棵树含残桩结束后才种苗，新苗不能被剩余队列又砍掉。
4. 棕榈消耗普通橡实；宝石树消耗对应宝石橡实，例如红玉树用红玉宝石橡实，普通橡实不能替代。
5. 本次砍树若掉对应种子，优先消耗本次种子；没有时再消耗快捷栏／主背包，不使用旧地面种子、箱子或Magic Storage。
6. 无种子仍正常砍树；原位不能种则不扣料；已有树苗不重复种和扣。关闭天赋、上限0时不补种。

连续伐木材料上下文只保留当前这一棵；长时间停止（30秒）清除待补种记录，再清理残桩时可重新根据当前操作建立记录。特殊斧头的未知第三方自动种树逻辑不调用。
