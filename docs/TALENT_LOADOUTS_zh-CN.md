# 天赋方案：确认规则与实现任务

用户确认每套方案独立使用角色累计获得的全部天赋点（100点角色的战斗页与采矿页各可分配100点），同时只有当前方案生效。基线PR #17已合并，main为6be301e6d44ef405bc81bdea50dd9ed48c03c5fb；新分支feat/talent-loadouts，本批未授权合并。

## 规则

- 经验、角色等级、累计获得点数为角色共有；方案独立保存天赋等级、开关、子效果开关、所选强度与历史实际投入。
- 新增“当前方案”下拉选择及新建、复制、重命名、删除。新建空页／复制当前页后切到新页。名称最多32个字符，不允许控制符或富文本标记；名称可重复，操作按稳定ID区分。
- 当前已购等级迁移为第一套默认方案。初始只建一页，不替用户自动分配战斗或采矿天赋。
- 新页完整拥有累计获得的点数；升级奖励同步增加所有方案可用额度。退款只回到该页，删除页不向角色总点数加款，不能删除最后一页；删除当前页须界面二次确认，成功后切回剩余第一页。
- 复制保留历史实际投入、开关及强度，随后独立编辑，不重新按当前价格计费。服务器上限应用于每页购买和当前生效，不裁掉旧存档合法超限等级。
- 免费切换，不新增战斗锁定或玩法冷却；沿用原有服务器操作节流、防过期请求和死亡时不能操作面板的规则。
- 换页不初始化角色、不恢复生命／魔力、不重置已有冷却或空中已用跳数；最大属性变化沿用原有只裁剪、不隐式回复规则。停止旧的批量作业并取消未完成的树苗补种上下文。
- 只当前页提供效果；Alt／G／K等免费角色操作状态不另存进每页，服务器配置仍为全局。
- 沿用有界存档／联机快照，触及容量时新建、复制或加点事务失败并提示，已有数据保持；不是扣点购买页数。不承诺无限字节容量。
- 存档v4完整保存所有页与当前选择，支持旧v1／v2／v3迁移；联机协议18。升级后不能用旧版读取新存档，安装前备份，服务器与客户端必须同版。
