# 0.9.0 玩家安装与验收说明

本批增加六项天赋，共87项。正式已验收基线仍为0.8.2；本包等待玩家验收，不代表新PR已合并。目标环境：tModLoader v2026.07.3.0 / Terraria 1.4.4.9 / .NET 8。存档仍为v3，联机协议升到11，联机所有端应使用同一版本。

## 安装

1. 退出游戏，备份正在使用的角色存档。原有等级、天赋、开关、强度和实际投入应保留。
2. 解压玩家测试包，将 `TerrariaProgression.tmod` 放到tModLoader的 `Mods` 文件夹，替换旧版同名文件。可从游戏“模组”菜单打开模组文件夹。
3. 启动游戏，确认模组显示0.9.0，再进世界按P打开天赋页。包内 `BUILD_INFO.txt` 记录精确提交和构建检查，反馈问题时一并提供。
4. 完整源码包用于查看或自行编译；不要把测试用 `ProgressionHarness` 安装进正常游玩环境。玩家包不包含它。

## 一次完成本批检查

可使用测试角色；需要点数时沿用 `/tpgivexp 数值`。先确认已有常用天赋等级和投入没有变化。下表的六项均1点/级、默认无限升级、支持当前强度调节。

| 菜单位置 | 新天赋 | 1级 | 10级 |
|---|---|---|---|
| 战斗与召唤 → 异常攻击 | 异常伤害强化 | 支持的天赋异常伤害+20% | 原生基础持续伤害3倍 |
| 同上 | 攻击附加霜冻 | 2秒 | 20秒 |
| 同上 | 攻击附加诅咒焰 | 2秒 | 20秒 |
| 同上 | 攻击附加毒液 | 2秒 | 20秒 |
| 同上 | 攻击附加灵液 | 2秒 | 20秒；减防不增加 |
| 采集与钓鱼 → 钓鱼强化 | 渔力提升 | 基础渔力+5 | 基础渔力+50 |

### A. 菜单、点数和存档

1. 在上述两个分组查找新天赋，也试一次全局搜索“异常伤害”或“渔力”。原有攻击附加燃烧／中毒继续保留。
2. 任选一项升到10级，应投入10点。把当前强度调低，等级和投入应保留。
3. 关闭该天赋，点数不应返还；退款后返还实际投入。
4. 保存退出并重新进入，确认留下的新天赋等级、当前强度和开关仍一致。

### B. 新异常与伤害强化

1. 使用没有原带异常的普通武器。先只启用一种攻击异常，买1级，打一次可受该异常影响的敌人，停手观察约2秒；再升10级比较持续时间。敌人可能提前死亡，免疫的敌人不会中对应异常。
2. 分别试霜冻、诅咒焰、毒液和灵液；重复命中只刷新时间，不把每次20秒累加。
3. 选择一种持续伤害异常，配合“异常伤害强化”10级。在同类敌人上比较强化开启／关闭后的掉血；自动检查会测量五种原生持续伤害的3倍关系。飘字是原版批量显示，不要求每个数字刚好翻三倍。
4. 敌人仍带异常时，调低伤害强化当前强度或关闭它：额外伤害应减弱／停止，已有异常应继续自然结束。只购买伤害强化本身，不应凭空给敌人施加异常。
5. 关闭所有攻击附加异常，只用自带异常的武器攻击：“异常伤害强化”不应强化这个纯武器来源。
6. 用召唤物尝试一次：召唤物有效命中也应施加启用的异常。灵液仍是原版减防，伤害强化不会提高减防。

关闭攻击附加天赋只阻止新施加；已施加异常按原有效期结束。多人同种异常的额外伤害取仍有效来源中最高值，不把玩家加成相加。武器延长了原生异常，也不能延长某个玩家天赋来源的增伤有效期。

### C. 渔力与扫描

1. 打开钓鱼信息显示，装备同一根鱼竿和同一种鱼饵；尽量在相同天气、时间和位置对照。渔力提升1级提供基础+5，10级提供基础+50；最终显示仍受原版天气、时间等倍率影响，不保证最终读数差刚好50。
2. 与增加渔力的装备同时使用，应叠加；关闭或把强度调到0，天赋贡献应消失。
3. 运行 `/tpscanaccessories`，打开新导出的JSON：`ModVersion` 应与加载版本一致。渔夫耳环应关联渔力；砌砖器关联方块放置速度，便携式水泥搅拌机关联墙壁放置速度；信息饰品与组合饰品仍保留部分覆盖说明。
4. 未映射数量不要求为0。扫描只读取已加载信息，不执行未知饰品效果；“已映射”也不等于第三方兼容已验收。

## 单列的可选补验

药水病缩短、原有钓鱼产量仍未实机验收。方便时可以在本包中试喝血药后的冷却和钓起物品数量，反馈时分别注明；不方便可以跳过，不能因此把它们自动改为通过。

真实多人、特殊／多阶段Boss、多人独立掉落增产仍保留各自未验收／未完成状态。多人来源自动检查不等于两个真实客户端实机验收。分层暴击继续按用户决定暂缓修复；本批没有加入P3世界操作。
