# P2-A 0.4.1 安装与验收

本包验证状态见 BUILD_INFO.txt 与 PR 中的自动测试结果。用户已授权推送与自动测试；合并仍需单独授权。

先退出世界并备份角色（.plr 与 .tplr），用包内 TerrariaProgression.tmod 覆盖 Mods 中同名文件，再重载。不要同时留两份。升级后保存为v3；旧版MOD不能读新档，回退需恢复备份。源码包用于开发，不用放进Mods。

服务器与客户端都更新到0.4.1。单人测试即可先验收；真实多人测试仍保留待办。

## 从0.4.0更新后的复查
自动跳跃天赋已取消。旧角色若购买过，载入时自动退回实际支付的点数（正常为2点），无论此前是否关闭；再次重进不会重复退款。其他天赋保持。真实装备提供的自动跳跃不受影响。

用户已确认本批除自动跳跃外的所有功能测试成功。本次只需重点确认自动跳跃条目消失、退款正确、重进不重复退款；其余步骤留作参考。

## 最短准备
在 MOD 配置中开启“开发测试命令”，进入测试角色输入：

```text
/tpgivexp 1000000
/tptalents
```

按P也可开关页面。已有角色继续沿用原有等级、天赋和点数。

## 1. 每级天赋点
服务器配置新增“每级获得天赋点”，直接填整数，默认1，不限于滑块范围，0停止发点。单人可从菜单设置；联机请开服前设置，专服改配置后重启。

用新角色，先设置5，然后输入 `/tpgivexp 1000`：应为4级、15可用点。改成1后不会立即补发或扣除旧点数；以后每升一级给1点。可填写100000等大整数，不支持负数、小数和科学记数法。非法值恢复1。

## 2. 功能页与基本开关
“功能能力”现在按移动、环境、信息、免疫、建筑/工具分组。

无坠落伤害、水上行走、岩浆表面行走、水下无限呼吸、岩浆免疫、炽热方块免疫、击退免疫、全信息显示：每项只解锁一次，花2点。解锁后购买按钮不能重复扣点。关闭不退点，回退返还2点。

先卸下可能提供同类效果的饰品，逐项启用/关闭比较。水上行走也适用于蜂蜜；岩浆表面行走与岩浆伤害免疫分别购买。炽热方块免疫不等于免疫火焰攻击。岩浆行走只支持普通重力方向。

## 3. 多段跳
每级1点，每级多1次空中跳跃。先买3级，起跳后松开再按跳跃，最多额外跳3次；落地恢复。把当前强度调到1后，只能额外跳1次，已投入仍为3点。空中关开不能补次数；和真实云瓶等额外跳跃加算。原版抓钩刷新也会恢复次数。

## 4. 全信息显示
花2点解锁，右侧详情下方有12个子开关，可滚动。关闭罗盘应只停止天赋提供的罗盘，时间等其余内容保留，点数不变。真实饰品和队友仍可提供同类信息。宝藏探测是原生宝藏高亮；可以单独关闭。

请顺带检查200%界面缩放：按钮文字不重叠，子开关可滚动、可点击。

## 5. 方块破坏效率
每级1点，初始默认每级+20%效率。10级时约为原来的3倍效率（受整数帧取整影响）。用相同的镐挖普通石块、斧砍树、锤拆木墙，分别比较关闭与启用。调低强度、退款后应恢复对应速度。

它不提高镐力，不让铜镐挖掉神庙砖，不放大拆除范围，也不提高放置方块速度。矿物/木材产量是独立天赋。原生特殊工具和其他MOD自行实现的工具需另行验证，最低仍是一帧一个动作间隔。

## 6. 存档复查与反馈
重进、换世界、死亡后，等级、点数、启停、多段跳强度、信息子开关均应保留。已有0.3.1角色的原天赋保持。若报错，请发截图与client.log；联机另附server.log及MOD列表。

优先反馈：加载是否成功、2点扣退是否正确、多段跳次数、镐/斧/锤三类速度、信息子开关及200%排版。没有实际测试的项目不算通过。
