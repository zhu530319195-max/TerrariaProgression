# 全服经验共享：确认规则与任务

2026-09-15，用户确认“每人全额获得经验”。本批从PR #16已合并main `0a5a4485bc5f1f40318f1907be83693e97a7b20a`建立独立分支`feat/server-shared-experience`。授权实现、测试、PR与测试包；之前的合并授权仅适用于PR #16，本批未合并。

## 已确认规则

- 新增服务器开关“全服经验共享”（ShareExperienceServerWide），默认关闭，旧配置缺省亦关闭。
- 关闭：维持按有效伤害贡献分配，包括原有离线份额不重分配规则。
- 开启：每次合法击杀结算时，所有当前在线且角色数据初始化完成的玩家，各得本次完整经验，不平分、不额外叠加贡献份额。
- 不限制距离、队伍或是否参战，等待复活的在线玩家也可获得。
- 离线者不获得，无补发；结算完成后才上线的人不追溯领取。结算前已加入且数据就绪的人按当时在线名单领取。
- 开关只影响今后的结算，不同步旧等级、不补齐历史经验、不改玩家既有天赋投入。
- 仍须存在合法玩家伤害贡献；纯环境击杀或无归属击杀不因开启共享给全服刷经验。
- 沿用原经验预算、生命倍率、雕像倍率、城镇NPC排除、击杀完成与多实体去重。共享复制的是一个合法遭遇的最终经验预算，不按参与人数或NPC部件重复叠算。
- 经验只由服务器／单人权威端结算。开发命令和其他直接授予经验入口不自动广播。
- 按实际结算时的服务器开关决定模式。配置权限维持现状：开服前设置，专用服务器修改配置后重启；不新增客户端远程改服权限。
- 不新增天赋或点数消耗，仍100项。存档v3、协议17保留：没有新增角色存档字段或自定义消息；选项使用tModLoader既有服务器配置同步。
