# 0.12.0 镐力、斧力、爆破范围与默认快捷键：安装及验收

95项天赋；存档v3，联机协议15。目标：tModLoader v2026.07.3.0 / Terraria 1.4.4.9 / .NET 8。当前为玩家验收版，尚未合并；自动检查成绩和功能提交见包内BUILD_INFO.txt。

## 安装

1. 退出游戏，备份角色、世界及旧版成长MOD。
2. 在tModLoader的模组管理中打开模组文件夹，用测试包内`TerrariaProgression.tmod`替换旧版，只启用一份。不要安装ProgressionHarness。
3. 重新加载，进入测试世界。原等级、天赋、投入点数应保留。联机双方都必须是0.12.0；协议14不能与15混用。
4. P打开面板。若此前自行改成其他键，继续用原自定义键；聊天输入`/tptalents`也能打开。

## 先测默认快捷键

1. 升级前没有给本MOD设过按键，或旧版本三项按键为空：首次启动新版后，不进设置，直接按P应打开天赋面板。
2. 学习范围挖矿后，按一下左Alt并松手，再正常挖石头，应启动范围挖掘；再按一下关闭。G切换范围挖矿／矿脉。伐木、范围收割沿用这个开关。
3. 若升级前已改键，例如面板设O：更新后仍应是O，不改回P。
4. 进入“设置 → 控制 → 模组控制”，自行改键，退出并重启游戏，改键应保留。
5. 新版已启动过一次后，主动清空其中一项按键，再退出重启；该项应继续为空，不会强制填回。
6. 若切换到此前未用过的输入配置，空的本MOD按键应补齐一次。不会重置原版或其他MOD设置。不同MOD之间可能共用相同默认键，可按个人习惯修改。

## 镐力增强

位置：“建筑与工具 → 工具效率 → 镐力增强”。每级1点，每级加10个百分点，Lv.10加100个百分点。

1. 准备铜镐与几块陨石。在关闭镐力增强时，用铜镐挖陨石，应挖不动。
2. 购买2级并启用：铜镐由35%变55%，应能挖陨石。背包工具提示会显示天赋后的有效镐力；物品自身的基础数值保持原样。
3. 关闭此天赋，再挖另一块陨石，应重新挖不动。重新启用，开启范围／矿脉采集，应也使用增强后的镐力。
4. 用同一把工具对比Lv.1与Lv.10，再降低当前强度；有效镐力应跟随当前强度，已购等级和投入不变。
5. 高镐力可跨过镐力门槛，但仍不能破坏原版明确禁止破坏的目标；范围采集仍保留家具、电线等保护。

## 斧力增强

位置：“建筑与工具 → 工具效率 → 斧力增强”。每级1点，每级加10个百分点，Lv.10加100个百分点。

1. 使用铜斧，暂时关闭“方块破坏效率”及一键伐木，对比斧力增强关闭／Lv.10时砍同类普通树。启用后应更少敲击即可砍断，工具提示中有效斧力增加100个百分点。
2. 再启用一键伐木，按Alt开启批量。增强斧力应同样生效，不会因为一键伐木而重复加算。
3. 将斧头交给未学此天赋的另一个角色，工具基础斧力应正常；退出重进后不应在物品上永久留下增幅。
4. 破坏效率仍是独立的出手间隔增强，可与斧力一起使用；特殊斧头的自动种树等批量附加行为仍未专门适配。

## 爆破范围增强

位置：“采集与钓鱼 → 挖掘与伐木 → 爆破范围增强”。每级1点，每级在原版地形爆炸半径外加1格。普通炸弹基础半径4格、雷管7格；Lv.10分别为14格、17格圆形地形半径，不是21×21方形。

1. 在测试世界远离建筑处准备两片相近的石头区域，保持Alt关闭。关闭此天赋，用普通炸弹炸第一片；启用Lv.1，再炸第二片，应多破坏外圈石头。
2. 改为Lv.10，再试炸弹、粘性炸弹、弹力炸弹、雷管、粘性雷管、弹力雷管。六种都应扩展地形破坏。调低当前强度后外圈变小；关闭后恢复原版。
3. 外圈按帧处理，会在原爆炸之后逐渐完成。它不增加爆炸伤害，也不让更远的敌人受到伤害；背景墙只保留原版爆炸本来会破坏的部分，不跟随新增外圈扩展。
4. 在新增外圈放带电线／执行器的石块、家具附近的支撑块，外圈应保留它们。原爆炸核心仍按原版规则破坏，不提供整颗炸弹的建筑免疫。
5. 肉山前，新增外圈不应炸掉原版当前不可炸的陨石／狱石；地牢砖、神庙砖和配置保护区也不由外圈拆除。手榴弹、炸弹鱼、甲虫炸弹、火箭、土炸弹、液体炸弹、第三方爆炸物不属于本批六种。
6. 单人设置中将“每次操作最多方块数”设为5，炸普通石头：原版核心照常爆炸，新增外圈最多破坏5块并给出上限提示。改回1000；设0表示不设每次数量上限，但每帧预算仍有效。
7. 将每帧采集预算调为1，再用较高强度爆炸，处理中关闭爆破天赋：剩余外圈应停止；已破坏的不会恢复。Alt关闭不会取消爆破扩展；它只取消工具的批量作业。
8. 关闭服务器“允许爆破范围增强”或采集总开关：不再增加外圈，原版炸弹本体仍正常。爆破和工具采集共用全服每帧预算。

## 点数和旧功能回归

三项新天赋都支持+10／+100／+300／+1000，单次上限1000不代表总等级上限。点数不足不部分购买。关闭不退款，回退／退款返还实际投入，调低强度不降低已购等级。工具结算上限为100000%有效强度；保存等级和投入仍可继续增长。极大爆破范围最终受世界边界及服务器预算限制。

确认Alt开关式范围挖矿、矿脉、一键伐木仍能使用；范围结束留块能直接补挖；普通镐单株收割正常；范围收割保留幼苗，自动补种缺种子仍可收获。

本批自动检查不等于真实多人通过。药水病缩短、原有钓鱼产量仍未实机验收；真实多人暂缓；特殊／多阶段Boss覆盖、多人独立掉落增产尚未完成；分层暴击暂缓修复。攻击破坏地形、扩大拆墙／建筑能力仍为候选。
