# 0.12.1 安装与验收：原版即时爆破、挖矿保护开关

95项天赋，存档v3，协议16。环境：tModLoader v2026.07.3.0 / Terraria 1.4.4.9 / .NET 8。继续PR #15，待本次实机复验；包内BUILD_INFO记录实际源码提交及自动成绩。

## 安装

1. 退出游戏，备份角色、世界与旧版MOD。
2. 在模组管理中打开模组文件夹，用包内TerrariaProgression.tmod替换旧版，只启用一份，不安装ProgressionHarness。
3. 重载进入测试世界，原有等级、投入、天赋应保留。P打开面板；若已改键，用自己的按键，或输入`/tptalents`。
4. 若联机，所有客户端和服务器同时更新至0.12.1；旧协议15不能混用。真实多人仍暂缓验收，自动网络检查不代表实机多人通过。

## 先测挖矿保护

1. 学习1级范围挖矿，拿镐子，按一次Alt开启批量，G选范围模式。
2. 默认额外保护关闭。挖普通石头旁的沙子、带电线方块：范围内应照常尝试挖，不因这些类型额外跳过。挖掉支撑时，沙子下落和家具掉落按原版发生，连带掉落可能在范围边缘之外。
3. 按一下K：应提示“挖矿额外保护：已开启”。换一片区域再试：沙子、线路、家具支撑和配置保护区应按以前的保守规则保留。
4. 再按一下K关闭，应恢复逐格原生挖掘。原版当前镐力不足或不允许拆除的目标，两种状态都不能强挖。纯镐不会获得斧／锤能力。
5. 面板选择范围挖矿或矿脉连锁，应显示“挖矿保护：开启／关闭”，右侧同名按钮可以免费切换；备用命令是`/tpgather protect`。
6. 大范围挖矿还在处理时切换保护，应停止当前挖矿作业；下一次挥镐按新状态执行。退出世界重进，批量开关与额外保护都默认关闭。
7. 矿脉依然只挖八方向相连的同种矿石；一键伐木的整树规则、范围收割保留幼苗、自动补种事务不改变。挖矿继续分帧，服务器总许可、距离检查和每次方块数量限制仍生效。

## 再测一次性大爆炸

位置：采集与钓鱼 → 挖掘与伐木 → 爆破范围增强。每级1点，地形半径每级+1格，可调强度，等级无限。

1. 在测试世界远离建筑处准备两片普通石头。Alt保持关闭，先关闭爆破天赋，用普通炸弹炸第一片；启用Lv.3后炸第二片，应在引爆时直接炸出更大的整圆，不再随后一格格挖外圈。
2. 分别测试炸弹、粘性炸弹、弹力炸弹、雷管、粘性雷管、弹力雷管。六种均生效。普通炸弹基础半径4格、雷管7格，Lv.10分别为14格、17格；不扩大伤害数值或伤害范围。
3. 在扩大范围内放沙子、带电线／执行器的方块、家具支撑。按原版炸药可破坏的应被炸毁，不再受到挖矿保护开关或配置区域过滤。原版当前不可炸的目标仍保留；天然连带下落／家具掉落按原版发生。
4. 背景墙请做两组：第一组让整个扩大范围都有连续背景墙，爆炸不应强制清墙；第二组让扩大范围内有一格没有背景墙，再引爆，应按原版规则炸掉可破坏背景墙。可以把缺口放在原基础半径外、新增范围内，确认判定用的是扩大后的范围。前景方块被挖空不等于背景墙有缺口。
5. 服务器设置“最大实际爆破半径”默认32格，可设7～128。将它改为8，学习更高等级后爆炸：应得到半径受限的完整圆形，不是炸到某个方块数量后出现半圆或缺角。实际破坏形状仍受原生不可炸目标影响。
6. 将采集“每次最多方块数”临时设1、每帧预算设1：增强爆炸仍应一次完成完整有效范围，只有挖矿等工具作业受这两项预算影响。测完恢复原设置。
7. 关闭爆破天赋或“允许爆破范围增强”，应恢复普通原版炸弹；Alt、K不控制炸药。火箭、手榴弹、炸弹鱼、甲虫炸弹、液体炸弹、土炸弹及第三方爆炸物不在本批六种名单中。

## 快捷键与已通过功能回归

- 默认P开面板、左Alt开关批量、G切范围／矿脉、K切挖矿保护；均可在设置 → 控制 → 模组控制中改绑。
- 0.12.0已设定或主动清空的P／Alt／G应原样保留；本次只给新K键补齐一次。K改键或主动清空后，重启不应恢复默认。
- 镐力／斧力保持每级1点、+10个百分点，Lv.10加100个百分点。铜镐原35%，镐力增强2级后55%可挖陨石，关闭后重新挖不动；斧力在普通砍树与一键伐木均只加一次。
- 新三项支持+10／+100／+300／+1000，点数不足不部分购买。可调强度、关闭不退款、退款返还实际投入，存档等级不受引擎有效强度／半径上限截断。

药水病缩短、旧钓鱼产量仍未实机验收；真实多人暂缓；特殊／多阶段Boss覆盖与多人独立掉落增产未完成；分层暴击暂缓，特殊斧头批量种树仍未适配。
