# 无尽潜能 0.15.1：天赋方案测试

本版可以保存战斗、采矿等多套加点。角色累计获得100点，每套都能各自分配100点；切换后只有当前方案生效。

## 安装

1. 退出游戏，先备份角色的 `.plr`、`.tplr` 及备份文件；使用云存档的角色先下载到本地再备份。
2. 解压测试包，把 `TerrariaProgression.tmod` 放进 tModLoader 的 Mods 文件夹，替换旧版。游戏内名称是“无尽潜能 · Boundless Potential”。不要启用开发用的 ProgressionHarness。
3. 启动后确认模组版本为 **0.15.1**。目标 tModLoader v2026.07.3.0 / Terraria 1.4.4.9。
4. 用原角色进入世界，按 **P**。原有经验、等级、加点和剩余点数应保留在“方案 1”。

本版存档升级为v4，联机协议18。v4角色不能直接交给0.14.0及更早MOD读取（0.15.0→0.15.1不再改变存档版本）；想回退必须恢复升级前的角色备份。联机时客户端与服务器都用0.15.1。

## 本次先复验这两项

### 1．名称输入

1. 按P → 改名 → 用退格删掉旧名字。
2. 切中文输入法，输入“战斗方案”；完成选字后用鼠标点“确认”。应能正常输入并保存，回车选字不应打开聊天框。
3. 再试英文、数字，以及“新建”“复制”中的名称。搜索框也应能输入。
4. 取消、关闭面板后，角色移动和原有快捷键应恢复；输入名字期间，数字、P等不得切换方案或关闭天赋面板。

### 2．一键切换与自定义

1. 先准备至少两套方案，面板顶部／列表显示 **[1]、[2]**。关闭面板。
2. **按住Shift，再按1**：切到第1套；Shift＋2切到第2套。左右Shift均可。
3. 按P确认当前方案和加点正确。数字键应只切方案，不同时切对应快捷栏格子。长按组合不会连续切换。
4. 默认还有Shift＋3～9、Shift＋0，分别对应第3～10套；不存在的方案不会被创建。
5. 打开 **模组配置 → 无尽潜能：天赋方案快捷键（本机） → 自定义快捷键列表**，展开需要修改的条目。例如把“方案序号”设为2，把“按键或组合键”改成 `Ctrl+F1`，保存并退出设置。
6. 回游戏，按住Ctrl再按F1，应切到第2套。也支持 `Alt+Q`、`Ctrl+Shift+2`、单键 `F6`；小键盘写 `NumPad1`。不用修改代码或配置文件。
7. 清空某条的组合键可以停用；关闭“启用方案快捷键”则全部停用。可通过列表加号添加更多方案的快捷键。重启后改键与主动清空应保留。
8. 打字、聊天、牌子／箱子改名、设置菜单、失焦和死亡期间不应切换方案。

序号按方案列表顺序，改名不改变序号；删除前面的方案，后面的序号会前移。重复组合以列表第一条为准。组合键要按示例填写，空白或无效格式不执行；请避开其他MOD已经使用的键。不要把聊天、回车或游戏暂停等常用键设成单键方案快捷键。

本版继续修订PR #18，未合并。中文输入法和实际界面仍以本次实机复验为准，以下是完整方案检查步骤。

## 最重要的测试：两套各用100点

角色不一定正好100点，用自己的总点数测试即可。“总点数”是当前可用点数＋当前已投入点数。

1. 在面板顶部点 **改名**，输入“战斗”，点确认。原加点应原样保留。
2. 点 **新建**，输入“采矿”，点确认。新方案立即启用，加点为空，可用点数应等于角色累计获得的全部点数。
3. 给采矿方案点镐力、基础方块产量、范围挖矿等。可以把这套的点数全部花完。
4. 点顶部 **当前方案**，选择“战斗”。战斗加点和余额应恢复，采矿方案的天赋不再生效。
5. 战斗方案也可以独立把全部点数花完。例如累计100点，就能同时保存一套花100点的战斗方案、一套花100点的采矿方案。
6. 来回切换几次，确认当前加点、余额和能力跟随所选方案，没有两套叠加。

## 复制、强度、开关与退款

1. 当前方案找一个可以调强度的天赋，例如镐力。购买后降低当前强度，再关闭另一项已购天赋。
2. 点 **复制**，输入“试验”，确认。新方案应与来源方案加点、开关、强度、已投入和剩余点数一致。
3. 在“试验”中退款一项，或点全部退款。点数只退到“试验”，不增加角色总额度。
4. 切回来源方案，确认原加点、开关、强度和余额没有改变。组合天赋的子开关也应分别保存。
5. 中文名称直接输入，输入法选字后点击面板的“确认”。空名称、超过32字符或含方括号的名称不能提交。

## 升级与存档

1. 记下两套方案的可用点数，切到其中一套，正常打怪升一级。
2. 两套可用点数都应增加服务器规定的每级点数。默认各加1；若设置每级3点，则各加3。
3. 留在“采矿”方案，退出世界并重新进入。应仍选中“采矿”，所有方案名称和加点均在。
4. 死亡复活后检查，方案和点数仍保留。

## 切换不回复资源、不继续旧采集

1. 在一套中购买生命／魔力上限，另一套不购买。先损失一些生命和魔力。
2. 来回切换。提高上限时不会自动回血、回蓝；降低上限时超过新上限的部分会被裁掉，切回也不会补回。
3. 喝药后切换，药水冷却应继续；空中多段跳用过的次数不能靠切换重置。正常回血、自然回蓝仍会按游戏时间运行。
4. 开启Alt，用大范围挖矿或拆墙开始一段尚未结束的作业，立刻换方案。剩余作业应停止。
5. 普通伐木从树干中部砍断，保留树桩，然后换方案：之前那次等待完成的补种机会应取消，不扣橡实。换页后的新砍伐会按新方案重新判断。
6. Alt、G、K状态属于角色，切换方案不另存一套；K的原默认关闭规则保留。

## 删除与服务器限制

1. 当前切到“试验”，点删除，再点取消：任何数据都不变。
2. 再点删除并确认：只删这一套，自动选中剩余第一套。角色累计点数不增加。
3. 仅剩一套时不能删除最后一套。
4. 可选：在服务器设置把某天赋上限降为0。每套都暂停该天赋生效，原已购等级和投入不消失。
5. 恢复上限后，各套原有等级按当前强度恢复。超限不能继续买，手动退款仍返还那一套的实际投入。

## 经验共享与联机

上一版“全服经验共享”开关保留。开启时每位在线玩家各得完整合法击杀经验；各角色再分别把升级所得点数加到自己的每套方案。

自动检查包括真实存档接口、原生属性与采集入口、服务器请求与快照，但不等于真人联机已通过。若方便实测：两人同版进服，一人切方案／改名／退款，另一人的方案和点数不能改变；重进后各自数据应保留。真人联机仍暂缓，不是本次必须补做的验收。

## 当前边界

仍100项天赋；新建、复制、切换免费。方案数据过多达到存档／网络容量时会拒绝操作，保留原数据，可先删除不需要的方案；不是额外扣点解锁页数。

本版等待用户实机验收，新PR不自动合并。药水病缩短、旧钓鱼产量仍待专项验收；真实多人、特殊／多阶段Boss、多人独立掉落增产和未知第三方MOD兼容性不作通过承诺。分层暴击及其他已暂缓／移出／取消事项不恢复。本批没有上传Steam创意工坊。
