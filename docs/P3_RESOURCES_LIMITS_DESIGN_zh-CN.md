## 已确认新增规则

预计新增4项数值天赋和1项一次性天赋，实现后预计100项。服务器等级限制为公共设置，不另收天赋点。以下拟定ID须在实现时核对唯一性，不变更旧ID。

| 任务 | 天赋／拟定ID | 价格与成长 |
|---|---|---|
| RES-01 | 基础方块产量／BasicBlockYield | 1点/级，产量+10%/级，Lv10为2倍 |
| RES-02 | 植物生长加速／HerbGrowth | 1点/级，速度+20%/级，Lv10目标3倍 |

所有新数值天赋默认无限升级，支持当前强度调节、批量加点和实际投入退款。服务器等级限制仅为可配置覆盖。一次性功能始终最高1级。

### 基础方块产量

天然和玩家放置方块一概增产，不追踪放置来源，不新增来源区分开关。普通挖掘、范围挖矿和能可靠确认实际操作者的爆破均适用。不用最近玩家推测归属。每份掉落只进入一种资源产量分类，既有矿石、木材、草药、宝石分类优先，不重复结算；宝石树的既有掉落分类不因本次基础地形扩展而自动改写。

首批具体覆盖建议如下，**尚待本轮集中确认**。以地形产生的相应方块物品为准，草皮先退化但未掉物时不凭空增产。实现时在固定版本核对TileID与ItemID映射。

| 组 | 具体方块（共27种） |
|---|---|
| 土质 | 泥土、淤泥、黏土、灰烬 |
| 石质 | 石头、黑檀石、猩红石、珍珠石、花岗岩、大理石 |
| 沙 | 沙块、黑檀沙、猩红沙、珍珠沙 |
| 硬化沙 | 硬化沙、硬化黑檀沙、硬化猩红沙、硬化珍珠沙 |
| 砂岩 | 砂岩、黑檀砂岩、猩红砂岩、珍珠砂岩 |
| 雪 | 雪块 |
| 冰 | 冰块、紫冰、红冰、粉冰 |

本建议不自动纳入泥沙、雪泥、沙漠化石等提炼原料，不扩展加工砖、家具、背景墙或未知MOD方块。它们可另行明确加入。既有矿石／宝石产量不变。

### 植物生长加速

首批仅原版七种草药：太阳花、月光草、闪耀根、死亡草、幌菊、火焰花、寒颤棘。保留各自原生生长、成熟和开花条件，不改变昼夜、天气或液体条件；合法地面、黏土盆、种植盆沿用既有农业边界。

固定人物附近范围，等级只提高速度，多人重叠取最高有效加成，不相加或相乘。强度关闭／服务器上限0时仅停止额外加速，不阻止原生生长。随机植物的三倍是生长速率目标，不承诺每株都在固定三分之一时间成熟，也不提前越过开花条件。

**待确认建议：人物中心半径50格的圆形区域，不要求视线，不受前景或背景墙遮挡。** 仅在线、存活且天赋生效的人物提供加速；离开范围、死亡、离线后不保留该人物的额外效果。实现必须限制扫描成本，不能靠无界逐级循环拖慢全服；具体引擎数值饱和须透明记录。

### 锤力与范围拆墙

锤力沿用镐力／斧力规则，只增强工具已有锤子能力，不永久修改物品，不影响他人持有同一物品时的属性。既有方块破坏效率已包含锤速，不另增锤速天赋。

范围拆墙共用Alt切换，半径以目标格为中心。范围内背景墙逐格按当前锤子敲击，保留原生墙壁拆除条件与破坏累计；不直接无条件删墙，不批量改变前景斜坡或敲祭坛。复用服务器实际操作者、距离／工具／会话／序号校验、分帧预算、每次总量设置和停止控制。G仍只切换范围挖矿／矿脉；K仍为额外挖矿保护开关，不据此给拆墙增加未经批准的地形过滤。

### 自动补种树苗

普通单棵伐木、一键伐木都可配合，不要求Alt开启。首批普通树、棕榈、宝石树，不连锁其他树。优先本次合法收获的种植材料，再用快捷栏／主背包；沿用草药补种的背包边界，不读箱子、虚空袋或外部存储。不挪用旧地面材料。

无材料照常砍树，补种失败不扣材料。原树残桩清理完且本次伐木结束后，才在合法原树根位置尝试补种。每树最多一次；已有树苗时不重复种植或扣料，后续队列不能再次清除新苗。普通中段砍伐若仍留残桩，须等玩家清完残桩；不凭该补种天赋自动授予一键伐木。取消／换工具等导致本次树未清完时不强行放苗。

**待确认材料细化：普通树、棕榈每棵1枚普通橡实；宝石树每棵1枚对应种类宝石橡实（紫晶／黄玉／蓝玉／翡翠／红玉／钻石／琥珀）。** 不用普通橡实凭空替代宝石橡实；未确认前不实现替代规则。官方ItemID目录分别定义七种GemTree…Seed：[tModLoader ItemID参考](https://docs.tmodloader.net/docs/stable/class_item_i_d.html)。

只在确实完成合法放苗后扣料并同步世界物品、背包和方块。未知第三方特殊斧头逻辑不自动执行；已存在树苗的检测应避免与原生工具的补种重复。

## 服务器天赋等级限制（CAP-01～03）

- 全局默认-1表示无限；0禁止获得和生效；正整数为指定上限。
- 单项覆盖优先，未列出的继承全局；单项同样支持-1／0／正整数。全局0时，可通过单项开放特定天赋。
- 应用于全部已注册天赋，包括已有95项与本批新增项；一次性功能固有上限仍1级。
- 降低上限不删除已购等级、不变更投入账本、不自动退款、不篡改已保存的玩家强度选择。实际生效取已购等级、玩家选择强度、服务器上限和功能固有上限的最小值，关闭时为0。
- 上限0暂停已有天赋，提高后恢复原有等级的可用性。角色从严限制服务器回到宽松服务器或单人时，不永久失去等级／强度设置。
- 超限购买按剩余可升级数裁剪；显示实际级数和价格，并按裁剪后的整次价格校验点数。不足时整次失败，不擅自改成尽可能购买。已购超过上限时阻止购买，但允许手动按实际投入退款。
- 面板区分已购等级、服务器允许等级和当前实际生效等级。技能开关与服务器禁用状态分开表达。
- “恢复默认天赋等级限制”按钮仅把全局改回-1、清空单项覆盖；不动其他设置、角色等级、强度选择或投入，不退款。
- 保留现有服务器配置权限：当前服务端拒绝游戏中客户端修改服务器配置。新按钮不能绕过此限制；单人／开服前配置页面或专用服务器原有配置途径应用设置。此次不增加远程管理员授权体系。
- 输入必须校验，使用稳定天赋ID匹配；大整数上限输入与现有无限等级相容，不能用浮点滑条改变数值。不把服务器上限当导入存档的合法等级上限，合法超限角色仍可加载。
- 检查配置默认值迁移与同步。存档v3优先保持；是否需要迁移及协议升级由实际传输变更决定，完成时记录准确版本，不把计划号当已实现事实。
- 配置影响全部效果入口与已排队世界操作，不仅限制界面按钮。最大生命／魔力限制变化不能造成隐式治疗／资源恢复。

## 持续保留的边界

即时原版整圆爆破及原生背景墙条件保留，不恢复延迟外圈或额外地形过滤。K额外挖矿保护默认关闭。自动跳跃、世界探索宝箱强化继续取消；液体／蜂蜜辅助、电线／执行器、独立跳跃高度移出计划；分层暴击暂缓。

药水病缩短、原有钓鱼产量仍未实机验收；真实多人暂缓实测，自动网络检查不等于真实多人通过；特殊／多阶段Boss适配和实机覆盖未完成；多人独立掉落增产／按玩家额外抽取未完成。未知第三方兼容性不作承诺。蘑菇、仙人掌、竹子、南瓜等植物扩展不纳入本批。
