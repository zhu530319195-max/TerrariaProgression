# P1-A 0.2.1 安装与测试

这是第一批数值天赋和天赋页面。共 21 项；P1 尚未全部完成。原有等级、经验、点数会继续使用。

## 安装

1. 退出当前世界。在 tModLoader 的角色管理中备份要测试的角色（或复制 Players 目录）。这是存档升级前的备份；新存档不能交回 P0 旧版使用。
2. 使用 tModLoader v2026.07.3.0（Terraria 1.4.4.9）。游戏菜单 → 创意工坊 → 管理模组 → 打开模组文件夹。
3. 解压测试包，把 `TerrariaProgression.tmod` 放入刚打开的 `Mods` 文件夹，覆盖同名旧文件。
4. 启用 Terraria Progression，重载模组。不要安装 `ProgressionHarness`（它仅供自动测试）。
5. 进入游戏，按 **P** 打开天赋页面。冲突时到“设置 → 控制 → 模组控制”更改按键；也可输入 `/tptalents`。

## 页面能做什么

- 顶部：角色等级、当前／升级所需经验、累计经验、可用和已投入点数。
- 分类：基础属性、恢复续航、战斗、经济资源；功能和超凡页提示后续开放。
- 选择天赋：查看等级、当前效果、下一级解锁效果、升级费用与实际投入。
- `升级 +1`：消耗 1 点；本批天赋等级不设游戏上限。
- `回退一级`／`此项全部回退`：返还实际支付点数。
- `启用`／`关闭`：只改变效果；关闭不退款，升级已关闭的天赋也不会自动开启它。
- 可对当前分类全部回退，也可全部启用、全部关闭、全部回退。
- 分类栏按可用宽度排列。升级／回退／启停按钮固定在右侧下方；仅天赋列表和文字详情滚动，内容能放下时隐藏滚动条。选中的分类与天赋高亮。
- 鼠标在页面上时不会穿透使用武器，滚轮不会切换快捷栏物品。

## 最简单的验收（新测试角色）

在 MOD 配置中打开“开发测试命令”：

```text
/tpstatus
/tpgivexp 1000
/tpstatus
/tptalents
```

应显示：**角色 Lv.4、50/490 XP、累计 1000 XP、可用 3 点**。

1. 给“最大生命”升一级：可用点数变为 2，已投入 1，最大生命 **100 → 125**。
2. 给“最大魔力”升一级：可用点数变为 1，最大魔力 **20 → 40**。
3. 给“防御力”升一级：可用点数变为 0，防御 **+4**；再点升级应不能继续扣点。
4. 关闭最大生命：最大生命回到 100；已投入和可用点数不变。当前生命高于 100 才截断至 100。
5. 再开启最大生命：上限恢复 125，**不会直接补满当前生命**。魔力同理；注意原版自然回魔仍会正常发生。
6. 防御回退一级：防御恢复，可用点数变为 1。
7. 全部回退：可用点数恢复为 3，所有本 MOD 天赋效果清除。
8. 重新分配点数，关闭其中一项；退出重进、换世界后，检查天赋等级、启停状态和点数都保留。

自然回血／回魔会随游戏正常运行，观察资源是否“瞬间补满”，不要把经过几秒的自然恢复误认为开关补满。

## 检查 Lv.10 强度

为新测试角色输入 `/tpgivexp 1000000`，逐次点选同一天赋 10 级。可全部回退后测试下一项。

| 天赋 | Lv.10 正常结果（不穿装备的基准） |
|---|---|
| 最大生命 | +250，上限 100 → 350 |
| 最大魔力 | +200，上限 20 → 220 |
| 防御力 | +40 |
| 移动速度／加速度 | 分别 +50% |
| 固定生命恢复 | +10 HP/秒，遵循原版恢复机制 |
| 自然生命恢复 | 原版自然回血部分 ×2 |
| 固定魔力恢复 | +20 MP/秒，自然回魔等待期也可恢复 |
| 自然魔力恢复 | 原版实际自然回魔速率再加 100%，等待期不额外恢复 |
| 物品治疗／回魔 | 对应恢复量 +50% |
| 全局伤害 | 装备加算区 +50% |
| 全局攻速 | +30%，受武器攻速继承与游戏帧数精度影响 |
| 暴击伤害 | 原版暴击 ×2 → ×2.5 |
| 护甲穿透／击退 | +30／+100% |
| 弹药节约 | 消耗概率乘 0.93¹⁰，约 48.4% 剩余消耗概率 |
| 魔力消耗 | 乘 0.95¹⁰，约 59.9% 剩余耗魔 |
| 召唤物／哨兵容量 | 各 +10 |
| 拾取范围 | 原有范围 ×2 |

已有装备加成、负面状态、伤害浮动和第三方 MOD 会影响最终显示。随机弹药节约需要多次射击观察。

## 联机与暂未验证项目

天赋操作由服务器校验点数和状态，客户端收到结果后才更新页面；不会通过客户端发送价格、经验或目标等级。

联机两端需安装同一版本。若页面显示请求尚未确认，等待提示后点“重新同步”，核对状态后再操作。联机 `/tpgivexp` 仍只允许专用服务器控制台 `tpgivexp <玩家槽位> <XP>`。

两个真实客户端的显示与交互尚需实机验证。P0 多人贡献、多节／多阶段 Boss 实机测试继续按用户决定暂缓。

掉率、金币／资源产量、暴击率与超额暴击、剩余 P1 项目尚未开放；P2/P3 效果没有实装。

- 错误截图、发生问题的操作和所选天赋。

- tModLoader 版本、启用的 MOD 名单。
- 页面显示问题：截图、分辨率与游戏 UI 缩放设置。

## 0.2.1 本次只需复测界面

0.2.0 的升级、快捷键与指令、启停不退款／不补满、回退、换世界和重启保存，均已由用户实机确认。0.2.1 仅优化页面与更新记录，成长规则和存档格式未变化。

1. 退出世界，用本包 `.tmod` 覆盖 0.2.0 并重载；原天赋保留，无需重新加点。
2. UI 缩放设置为 200%，按 P 打开页面。升级、回退和启停应直接可见，不用滚动到文字底部。
3. 检查分类／选中天赋高亮；切换最大生命与恢复类天赋，说明文字应连续排列。
4. 用滚轮滚动列表／长说明，确认操作按钮保持原位，点击位置准确。再试 100% 和 150% 缩放。
5. 如布局仍不理想，上传完整截图、分辨率和 UI 缩放值。
