# TerrariaProgression 0.8.0 安装与验收

本版：81项天赋、六个一级分类＋二级分组，新增鱼饵节约、宝匣概率和开发饰品报告。存档v3、联机协议10。PR #9的八项能力已验收，不要求重新逐项测试。

## 安装

1. 退出游戏并备份要测试的角色。
2. 在 tModLoader 的模组菜单打开 Mods 文件夹，将测试包内 `TerrariaProgression.tmod` 覆盖旧版同名文件。
3. 重新加载，确认版本0.8.0。不要安装完整源码包中的 ProgressionHarness，它只供自动测试。
4. 联机时服务器和每个客户端都更新到0.8.0。目标 tModLoader v2026.07.3.0 / Terraria 1.4.4.9。

## 1. 老角色与二级目录（优先验收）

- 用原有角色进世界，按 **P** 打开。核对之前的等级、可用点数、已购天赋等级和开关仍在。
- 点击左侧“战斗与召唤”，再点“异常攻击”：中间应只出现攻击燃烧、攻击中毒；本版没有异常伤害强化。
- 选择“移动与探索 → 飞行与游泳”：应看到飞行时间/速度、无限飞行、游泳速度、水上/岩浆表面行走。
- 点一级分类下“全部”，应显示该类全部天赋，没有未实现的空分组。
- 点选一个分组，关闭再打开P菜单，应仍停在这里。本版记忆范围为当前游戏会话。
- 在游戏原有UI缩放100%、150%、200%下检查：目录、天赋、详情各自滚动；右下操作区也可滚动。升级与退款按钮不应相互遮挡。

## 2. 搜索与筛选

- 点击上方搜索框，输入 **鱼饵**，即使原来停在生存分类也应找到“鱼饵节约”，并显示“采集与钓鱼 / 钓鱼强化”路径。
- 清空后输入 `FlightTime`，应能找到飞行时间；英文不区分大小写。
- 搜索输入中按P应输入字母，不关闭菜单。Enter结束输入；Esc先结束输入，再按一次Esc关闭菜单。点击框外应正常恢复操作。
- 开启“已购买”，关闭的已购天赋仍显示；再开启“已启用”，关闭或当前强度0的天赋应被过滤。
- 两个筛选同时开启时取交集。清空搜索、关闭筛选后列表应恢复。
- 若全信息或异常免疫已购买，选中后在右侧仍可使用原有免费子开关。

## 3. 退款范围

请在测试角色操作，退款返还实际投入，不会扣除已获得的等级经验。

1. 分别在“生命与魔力”购买一些最大生命、最大魔力，在“恢复与治疗”买一级生命恢复。
2. 查看“退款分组【生命与魔力】”显示的返还点数，点击后只有生命/魔力上限天赋退款；生命恢复保留。
3. 再买一级最大生命，另在移动类买一级移动速度；点击“退款分类【生存与恢复】”，应退还该分类所有已购天赋，移动速度保留。
4. 从其他分类全局搜索“飞行时间”，选中后分组/分类退款按钮应显示它自己的范围：飞行与游泳、移动与探索。
5. 筛选不会缩小退款范围：按钮按标注的完整分组/分类退款，不仅是屏幕上可见的结果。
6. 单个天赋关闭不返还点数；“回退一级”显示的是最近一级实际支付的点数。

## 4. 钓鱼准备

单人测试角色可在模组设置开启“开发测试命令”，再依次输入：

```
/tpgivexp 10000000
/tpfishsample
```

第二条领取金钓竿、大师鱼饵和声呐药水。到足够大的普通水池测试。为了观察方便，先关闭已有“钓鱼产量”，并暂时不使用会改变钓鱼流程的其他模组。

### 鱼饵节约

- “采集与钓鱼 → 钓鱼强化”，升到Lv.10。
- 详情应显示原消耗概率约乘48.4%，代表平均节约约51.6%，不是每次必定不消耗。
- 钓鱼仍需要鱼饵；多次收竿后观察消耗。将当前强度调到0、关闭、重新开启，观察说明和点数；关闭不退款。
- 单次或十几次收竿不足以证明概率。自动测试已覆盖大量原生收竿，实机重点看是否正常钓鱼、是否出现异常扣除或复制。

### 宝匣概率

- 升到Lv.10：原宝匣判定失败概率约乘59.87%；普通10%资格成为约46.11%。
- 在普通水池连续钓鱼，应明显更容易获得宝匣，种类仍符合当前环境与游戏进度。
- 关闭或降到0恢复原判定；已有宝匣药水可以叠加。蜂蜜不会凭空产出宝匣，岩浆仍需熔岩钓鱼资格并保留额外筛选。
- 本版增强的是钓鱼过程中的资格，不是保证每一竿成功，也不直接增加宝匣内的物品。

## 5. 饰品候选报告（可选）

开发命令开启后的单人输入：

```
/tpscanaccessories
```

聊天显示导出位置。一般在 tModLoader 保存目录下 `TerrariaProgression/Reports`，同名JSON和CSV两份。CSV可用Excel打开；JSON信息更完整。

- 应有“Mapped / Partial / Unmapped”三类；十字章护盾等组合装备为Partial。
- 未知MOD饰品应是Unmapped，而不是自动变成可购买天赋。
- 报告保留当前语言；另一语言未加载时为空，不代表物品没有名称。
- 扫描前后角色点数、已购天赋和能力不应改变。
- 不需要为测试额外安装第三方模组。报告中的映射状态不等于兼容性测试通过。
